ATC summary + NDC mapping · API source links included

Current and historical describe RxNorm associations, not marketing dates. Historical coverage follows currently related products and may miss older products.

API details & coverage

Ingredients: findRxcuiById matches the ATC code. Concept properties confirm active IN, PIN or MIN ingredients.

Products: getRelatedByType retrieves SCD, SBD, GPCK and BPCK products, including combinations. These are ingredient-linked products; their exact ATC classification is not independently verified.

NDCs: getNDCs supplies current codes. getAllHistoricalNDCs with history=2 adds dated associations, including those inherited from remapped products.

Result labels: “Current association” means getNDCs returned the code. “History API only” means it appeared only in historical results for the retrieved products. Failed or unfinished current checks are labeled incomplete.

Dates: First and last dates are RxNorm release months. The 2015–2026 overlap flag checks recorded intervals; no date filter removes other records.

ATC inventory: N03A uses the WHO 2026 substance list. Other classes use current RxClass members and may omit unmapped substances. Former N03A codes are excluded from class expansion.

Exports: Both CSVs include all retrieved rows, source links and lookup status. Import NDCs as text to preserve leading zeros.
